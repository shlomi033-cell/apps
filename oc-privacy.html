O.C – מדיניות פרטיות

דפדפן O.C ותוסף "O.C – סנכרון סימניות" לכרום · עודכן: 25 בנובמבר 2026

בקצרה

O.C לא אוסף מידע עליכם ולא שולח אותו לשום שרת שלנו. אין לנו שרתים. הכל נשמר אצלכם – בטלפון, בכרום שלכם ובגוגל דרייב שלכם.

מה התוסף לכרום עושה

  • קורא ומעדכן את הסימניות של כרום, כדי לסנכרן אותן עם דפדפן O.C בטלפון.
  • יוצר בגוגל דרייב שלכם קובץ אחד בשם OC_chrome_sync.json וכותב אליו את הסימניות.
  • ההרשאה לדרייב היא drive.file בלבד: התוסף רואה רק את הקובץ שהוא עצמו יצר, ולא שום קובץ אחר בדרייב.
  • החיבור לחשבון גוגל נעשה דרך כרום (Google Sign-In). אנחנו לא רואים את הסיסמה שלכם.

מה האפליקציה O.C בטלפון עושה

  • קוראת וכותבת לאותו קובץ בדרייב, רק אחרי שבחרתם אותו בעצמכם בבורר הקבצים של אנדרואיד.
  • היסטוריה, סימניות, הגדרות וגיבוי נשמרים בטלפון ובקובץ גיבוי בדרייב שאתם בוחרים.
  • סיסמאות לא נשמרות ב-O.C – הן מנוהלות על ידי מנהל הסיסמאות של גוגל (מילוי אוטומטי של אנדרואיד).

שיתוף מידע

אנחנו לא מוכרים, לא משתפים ולא מעבירים מידע לאף אחד. אין פרסומות ואין מעקב. השימוש במידע מגוגל עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

ביטול ומחיקה

  • ניתוק: בתוסף – "ניתוק החשבון"; ב-O.C – הגדרות ← נתונים אישיים ← סנכרון סימניות עם כרום ← ניתוק.
  • ביטול ההרשאה בכל זמן: myaccount.google.com/permissions.
  • מחיקת המידע: מחקו את הקובץ OC_chrome_sync.json מהדרייב.

Privacy Policy (English summary)

O.C (Android browser) and the "O.C – Bookmark Sync" Chrome extension do not collect, sell or share any personal data, and use no servers of their own. The extension reads and updates Chrome bookmarks and stores them in a single file it creates in the user's own Google Drive (OC_chrome_sync.json), using only the drive.file scope, so it can access only that file. The Android app reads/writes that same file only after the user picks it. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at any time at myaccount.google.com/permissions and delete the file from Drive. Contact: shlomi033@gmail.com
